# LGG 本机采集桥

采集桥让 GitHub Pages 中的“采集数据”按钮能够读取本机英雄联盟客户端。它只读取并返回数据，不登录 Supabase，也不会自行提交对局。

## 使用

1. 第一次使用时下载并运行 `install-collector.cmd`。
2. 登录英雄联盟国服客户端。
3. 在 LGG 中打开“记录正式比赛”，点击“采集数据”。
4. 如果采集器没有运行，点击网页中的“启动采集器”。
5. 检查网页展示的双方、英雄、KDA、补刀和胜方。
6. 确认无误后点击“确认提交”。

安装器会注册 `lggcollector://` 本机协议，并将运行文件放到
`%LOCALAPPDATA%\LGGCollector`。采集器不会开机自启；网页点击启动时才会
唤起，并在空闲约两分钟后自动退出。

采集桥会优先读取客户端赛后结算数据，其次读取最近一场历史对局；如果对局尚未结束，则尝试读取实时数据。实时数据无法确定胜方，需要用户手动选择。

## 自定义部署域名

默认只允许 `https://hyicode.github.io` 和本机网页访问。如果 LGG 部署到了其他域名，把 `config.example.json` 复制为 `config.json`，在 `allowedOrigins` 中加入该网页的 Origin，例如：

```json
{
  "port": 32145,
  "allowedOrigins": [
    "https://example.com"
  ]
}
```

采集桥仅监听 `127.0.0.1`，不会向局域网开放。客户端本机令牌只用于本次本机请求，不会返回给网页或写入磁盘。
